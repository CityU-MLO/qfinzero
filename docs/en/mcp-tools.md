## Research

### research_backtest

Backtest a factor as an intraday portfolio: every `rebalance` bars hold the top (and short the bottom) `fraction` of names equal-weighted, enter at the next bar's open, flat at the close. Costs: cost_bps per unit traded plus half the quoted spread (2 bps assumed without quotes).

| parameter | type | required | default | description |
|---|---|---|---|---|
| `expression` | str | yes |  | the factor |
| `start` | str | yes |  | YYYY-MM-DD trading-day range |
| `end` | str | yes |  | YYYY-MM-DD trading-day range |
| `universe` | list[str] |  | `null` | explicit tickers; default is top_n by prior-day dollar volume |
| `top_n` | int |  | `500` | size of the default universe (default 500) |
| `rebalance` | int |  | `15` | bars between rebalances (default 15) |
| `fraction` | float |  | `0.1` | share of names held per side (default 0.1) |
| `long_short` | bool |  | `true` | short the bottom fraction too (default true) |
| `cost_bps` | float |  | `0.5` | per-unit trading cost on top of the half-spread |
| `bar_minutes` | int |  | `1` | bar size (1, 5, 15, ...) |
| `session` | "regular" \| "extended" |  | `"regular"` | "regular" (default) or "extended" hours |
| `cross_day` | bool |  | `false` | let time-series windows span days |
| `session_id` | str |  | `null` | Optional PMB session to time-lock this query to (data after the session's current bar is hidden, enforced server-side). |
