# 对话

> English: [docs/en/chat.md](../en/chat.md)

*对话* 是基于 QFinZero 工具（行情、新闻与事件、模拟券商）的研究与交易助手。它使用你在 *设置* 中选择的模型；
密钥只保存在浏览器中，随每次请求发送。

## 对话管理

- **新对话** 开始一段对话，第一条消息作为标题（可在顶部或列表中的铅笔图标重命名，也可双击）。
- 左侧列表按时间倒序、按天分组列出你的对话，可以搜索标题和内容。删除前会再确认一次。
- 对话按登录用户保存在服务器上（`$QFZ_DATA_ROOT/_state/playground.sqlite3`，或 `PLAYGROUND_DB`），
  其他人（包括管理员）看不到。
- 对话会记住上次使用的模拟时间，再次打开时从那里继续。工具看不到该时间之后的数据。
- 地址中带有对话 ID（`/chat?thread=…`），刷新或分享链接都会打开同一段对话。

## 上下文管理

每一轮都会根据历史重建完整上下文：你的消息、助手的回答，以及每次工具调用和它的结果。

- **上下文窗口**（设置面板）是上下文要放进的大小，请设为模型的窗口长度。
- 工具结果占大部分空间。最近两次回答之前的工具结果截短到约 1,500 字符，最近的截短到约 24,000 字符；
  模型需要时可以再次调用工具。
- **自动压缩**：估算达到窗口的 80% 时，由模型总结最早的若干轮（保留最近两轮），摘要放进系统提示，
  这些轮次移出上下文，但仍保留在历史和导出中。顶部的 **压缩** 按钮立即执行，只保留最后一轮。
- 顶部的指示条显示估算的上下文大小和窗口、各部分组成、已压缩的消息数，以及模型返回的上次请求输入大小。

## 停止回答

回答过程中，发送按钮变为 **■**（也可按 Esc）。已经生成的内容会保留并标记为已停止，未完成的工具调用标记为已取消，
下一轮会告诉模型上一次被打断。关闭页面不会停止回答：它在服务器上继续运行，列表中显示加载图标，
打开对话可以看到进度，直到结束。

## 工具调用

每个模型步骤的工具调用折叠成一行，例如 *调用了 upq_stock_daily · 2 次 · 117 ms*。展开可以看到每次调用的记录：
参数、结果（行数据显示为表格，或 JSON）和耗时。

**运行过程**（回答下方，或展开的工具行中）打开运行视图：

- **流程**：把这一轮画成图：你的消息 → 模型步骤 → 它调用的工具（并行调用上下排列）→ 下一步 → 回答；
  下方是模型步骤和工具调用在同一时间轴上的时间线。点击节点或时间条查看输入、输出或文字。
- **记录**：按顺序列出每一步的文字和调用。

## 导出

**导出** 把对话下载为 Markdown，可以包含工具调用（输入和输出放在可折叠的 `<details>` 中），也可以只导出文字。
压缩过的对话会附上摘要。

## API

对话服务（`:19390`，经 `/api/playground` 代理）把每个请求限定在 hub 设置的 `x-qfz-user` 范围内。

| 方法 | 路径 | |
|---|---|---|
| `GET` | `/threads?q=` | 你的对话 |
| `POST` | `/threads` | 新建空对话 |
| `GET` | `/threads/{id}` | 消息及其步骤；`running` 和进行中的 `live` 回答 |
| `PATCH` / `DELETE` | `/threads/{id}` | 重命名 / 删除 |
| `POST` | `/chat` | 发送消息（不带 `thread_id` 则新建对话）；SSE 事件 `turn_start`、`context`、`compacted`、`step_start`、`llm_chunk`、`step_end`、`tool_start`、`tool_end`，最后是带保存后消息的 `done`、`interrupted` 或 `error` |
| `POST` | `/threads/{id}/interrupt` | 停止正在进行的回答 |
| `GET` | `/threads/{id}/context?budget=` | 上下文估算 |
| `POST` | `/threads/{id}/compact` | 立即总结较早的轮次（需要模型参数） |
| `GET` | `/threads/{id}/export?tools=` | Markdown |
